# PlayWright Leaning

Personal learning repository for the **Learn Playwright Batch 2x** course by [The Testing Academy](https://thetestingacademy.com).

## 📁 Repository Structure

```
.
├── Chapter_01_basics/            # Early practice files
└── LearnPlaywrightBatch2x/       # Official Batch 2x course content
    ├── chapter_01_Basics/
    ├── chapter_02_Javascript_Concepts/
    ├── chapter_03_Identifier_Literals/
    ├── chapter_04_Javascript_Concepts/
    ├── chapter_05_Literal/
    ├── chapter_06_Operator/
    └── README.md                 # Detailed course README
```

## 🚀 Quick Start

Navigate to the course folder and run any chapter file:

```bash
cd LearnPlaywrightBatch2x
node chapter_01_Basics/01_Basics.js
```

For the full curriculum, folder structure, and weekly plan, see the detailed [LearnPlaywrightBatch2x/README.md](LearnPlaywrightBatch2x/README.md).

## 🛠️ Useful Commands

```bash
# Run a JavaScript file
node <file.js>

# Initialize Playwright (Week 10+)
npm init playwright@latest

# Run Playwright tests
npx playwright test
```
